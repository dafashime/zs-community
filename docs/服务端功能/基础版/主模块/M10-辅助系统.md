## 关键跨模块事实(写作时已核实的坑)

1. **`net.send_old` 在本树是空桩**(`mir2.single.net.lua :: net.send_old`,L248-252 只打日志)。所有经它发送的报文——plugCheck 的 `CM_SPEEDHACKUSER`、bigmapOther 的 `@传送` ——**实际都不会上线**(详见 S4/S6)。
2. **4464 一个号码两用**:C→S 是 `CM_SYSTEM_NEWMAIL` 轮询,S→C 是 `SM_MAIL_INFO` 未读数推送,客户端按 ident 分流互不干扰。
3. **4495 同号回执**:清空邮件的应答使用与请求相同的 4495,客户端以 `CM_CLEAR_ALLMAIL == ident` 接收(`ui.lua` L2223)。
4. **旧邮件常量 8000~8004**(`SM_MAILLIST/SM_MAILITEM/SM_NEWMAILRESULT/SM_MAILOPT/CM_MAILOPT/CM_NEWMAIL/CM_MAILLIST/CM_MAILLISTEX/SM_MAILLISTEX`,globa1 L2105-2113)在本树无任何调用/处理,属遗留死常量。
