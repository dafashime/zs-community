# 主模块 M7 社交系统

M7 覆盖 Lua 客户端的四大社交域:**聊天频道**、**好友关系**、**组队**、**行会(含战队)**。本文档系列面向服务端实现者,只描述服务端交互(触发时机、CM 报文字段与 body 布局、SM 应答与错误分支),不涉及客户端 UI 渲染细节。

> 源码根:`client/src/`(基础版开发树)。
> 协议公共事实(帧格式/TDefaultMessage/record 对齐规则/GBK 编码)见 `工作底稿（未随仓库分发）/BRIEF.md`,本系列直接引用其结论。

## 模块边界

**属于 M7:**

- 聊天收发与频道体系(`mir2.data.chat.lua`、`panel.chat.lua`、`console.widget.chat.lua` 的发送路径、`common.lua` 富文本编解码)
- 好友/关注/黑名单(`mir2.data.relation.lua`、`panel.relation.lua`)
- 组队(`panel.group.lua` + `ui.lua` 组队分发分支 + `data.player.lua` 成员列表)
- 行会与战队(`mir2.data.guild.lua`、`panel.guild.lua`、`def.guild.lua` 常量)

**不属于 M7(交叉引用):**

- 聊天消息的屏幕八件套布局(聊天框/输入框等控件位置)→ 已在 [M4-S4-系统消息与提示](../子模块/M4-S4-系统消息与提示.md) 中描述,M7 只引用不重复。
- 摆摊(摊位开设/摊位交易,SM_START_STALL 等)→ 归属 M8 摆摊交易系统;摆摊叫卖语若经聊天通道下发,同样归 M8 描述,M7 不展开。
- 系统提示类文本(拾取/升级/错误 tip 等 SM_SYSMESSAGE 系统用法)→ M4-S4;M7-S1 只覆盖其作为"系统频道"聊天数据的承载方式。
- 结婚/师徒/门派:客户端仅有 `@允许求婚`、`@加入门派` 等口令常量(`mir2.def.cmds.lua`),经 CM_SAY 以 `@口令` 文本发送,**无专用报文**,在 M7-S1 中一句话带过。
