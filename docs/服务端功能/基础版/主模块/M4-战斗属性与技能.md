# M4 战斗·属性·技能

> 本模块覆盖 Lua 客户端"玩家自身能力数值、技能/魔法、物理攻击与受击、系统提示消息"四大域的服务端交互协议。
> 源码根:`client/src/`;消息号常量全部在 `mir2/mir2.def.globa1.lua` 中逐一 grep 核实。

## 模块边界

**归 M4:**
- 玩家(及英雄)属性/能力数值的下行解析与触发(SM_ABILITY 族)。
- 货币资本推送 SM_GETDIAMNUM_EXT(M8-S4 引用本模块 S1 的布局结论)。
- 物理/魔法攻击的发起(CM_HIT 系列、CM_SPELL)与服务端回执/广播族。
- 受击与血量数值类消息(SM_STRUCK、SM_HEALTHSPELLCHANGED、SM_OPENHEALTH 等)。
- 死亡/回生的数值与提示侧(SM_NOWDEATH 的回生提示;尸体呈现归 M3)。
- 系统提示/聊天八件套的 body 布局与颜色编码(M7-S1 引用本模块 S4)。

**不归 M4(交叉引用):**
- 移动物体呈现(走路/跑步/出现消失/地上物品)→ M3(`mir2.scenes.main.ground.lua` 的地图对象分支)。
- 攻击/施法/受击的动画、飘字等本地表现 → M3(role/ground 呈现层);本文只写到"客户端把某字段用于呈现"为止。
- 聊天上行 CM_SAY 与语音/图片聊天扩展 → M7(本文 S4 仅给出其引用的下行布局)。
- 装备穿脱引起的属性变化链路(SM_TAKEON_OK 等)→ 物品模块。
