# 白猪版(G2.5)服务端功能文档目录

> 本系列文档面向**重写服务端**的目标,基于 `client/src-bz/`(白猪 G2.5 全明文树:mir2 203 + core 82 + upt 6,另有 64 位镜像副本内容一致)挖掘客户端↔服务端交互报文。
> **定位 = 与基础版的差异文档**:白猪版与[基础版](../基础版/目录.md)协议高度同源(已脚本全量对比),本文档只展开差异与白猪专属行为,完整报文布局一律链接到基础版对应文档。
> 只记录交互协议,不记录客户端本地 UI/逻辑。所有消息号数值以白猪版 `mir2/mir2.def.globa1.lua` 为准。

## 一、与基础版的协议关系(已核实结论)

| 对比项 | 结果 |
|---|---|
| 消息号常量 | 2002 个**全部同值**;同名不同值 0;基础版独有 0;**白猪独有 4 个**:`SM_MAPWEATHER(57)`、`SM_MAP_RANGE_PICK(5044)`、`CM_USERRELIVE(4675)`、`SM_YSGUISHU(1314)` |
| 记录(结构体) | 127 个**全部同字段同布局**(2 个仅成员函数写法差异,不影响线上字节) |
| 帧格式/握手/心跳 | 完全一致(TClientMessage 12B + TDefaultMessage 12B;cmd 23/24/25) |
| 使用面 | 白猪版实际引用 630 个常量,基础版 601 个,共用 600;**仅白猪版使用 30 个(含悬空引用与本地事件借名),仅基础版使用 1 个(CM_DBLCLICKUSEITEM)** |
| 新增传输层 | **TigerGate 可选整帧编码层 + cmd=29 心跳帧**(见下;当前源码树默认关闭) |

结论:**重写服务端时,基础版文档的帧格式、记录布局、绝大多数报文可直接复用;白猪版文档补充 30 个使用面差异、4 个独有常量与 TigerGate 层**。

## 二、白猪版独有传输层:TigerGate 编码与 cmd=29(核心差异)

`mir2/mir2.single.net.lua`(白猪版)新增可选编码层,条件为 `count2 == 1 and def.openNewTigerGate`:

- `count2==1` = 携带 **sessionID 的第二次连接**(游戏网关/重连);首连(areaID)不受影响;
- `def.openNewTigerGate` **全树无赋值点**,运行时为 nil → **当前默认关闭**;若服务端/配置开启,所有上行帧(握手、SM_RUNGATEDYN 回执、LM_PING、全部业务消息)将变成**文本帧**:整帧二进制按 3→4 变体 base64(64 字符密钥表按上一帧 dataIndex 轮转)编码并追加 `"|LH"` 后缀;
- **cmd=29 心跳帧**:每 30 秒一条 `TClientMessage{cmd=29, dataIndex=时间戳}`(12B),已编码过一次后经编码发送;客户端不解析下行 cmd=29;
- 详见 [M1-S2](子模块/M1-S2-TCP握手加密与心跳.md) 与基础版对照。

## 三、白猪版使用面差异速览(30 个仅白猪使用)

**真上行(4+1 个)**:CM_RUN3(4108)、CM_PICKUP_RANGE(4278)、CM_SHANGMA_OK(4106)、CM_HEAVYHIT2(待核,globa1 无定义)、CM_TURN2(**局部变量名,非协议**)。

**真下行(8 个)**:SM_SHANGMA_OK(3413)、SM_XIAMA_OK(3414)、SM_MAP_RANGE_PICK(5044)、SM_ASS_BLOODHIT_MOVE(3558)、SM_YSGUISHU(1314)、SM_MAPWEATHER(57)、SM_LYHIT/SM_SFZHIT/SM_XHHIT(悬空,globa1 无定义)。

**本地事件借名(非网络)**:`mir2.single.bzEvents.lua` 事件总线的 `CM_FILTER/CM_MSGBOX/CM_ZONEMSG/CM_TIPS_SHOW/CM_CACHEJOB/CM_SETABIL/CM_NO_BACKCD/CM_UNLIMITEDMOVE/CM_BAN_ATTACK/CM_RSITEM/CM_BANMOVE/CM_CHANGEBAG/CM_TAKEOFF/CM_NEED_BAG_PASS/CM_PASS_OK/CM_FIX_RUN`(服务端指令串经 **CM_SAY 特殊前缀文本**通道回执,见 M6-S1/M7-S1)。

**仅基础版使用**:CM_DBLCLICKUSEITEM(1017)(白猪版双击使用走其他路径,见 M5-S1)。
