# M7-S4 行会

> 所属主模块:[M7-社交系统](../主模块/M7-社交系统.md) · 基础版对照:[M7-S4 行会](../../基础版/子模块/M7-S4-行会.md)

## 与基础版差异摘要

**协议无差异。** 行会/战队两级全部操作、12 个 record(TGuildDesc 56B/TCorpsDesc 64B/TGuildMember 31B packed/TCorpsMemDesc 48B/TLogDesc 64B 等)、showError 错误码、宣战/关注不同号应答——与基础版完全一致(基础版 M7-S4 详述)。

白猪版特有行为(聊天文本驱动自动刷新):`bz.functions.process_bz_cmd` 在收到战队/行会频道的特定文本("已经正式加入了本战队"等)后,自动补发 `CM_CORPS_MEMBER_LIST`(tag=30,series=0,recog=0,body={ID, corpsID})、`CM_CORPS_LIST`(param=0,tag=7)、`CM_GILD_LIST`(tag=7,param=0)、`CM_GILDMEMBER_LIST`(6 秒节流)——服务端在这些通知文本下发后应正常应答列表请求即可,客户端会自行刷新。

## 服务端实现要点

按基础版 M7-S4 实现;入队/入会通知文本会触发客户端自动刷列表,服务端保证列表消息应答即可。
