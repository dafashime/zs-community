# M3-S2 对象感知与角色呈现

> 所属主模块:[M3-游戏世界与场景](../主模块/M3-游戏世界与场景.md) · 基础版对照:[M3-S2 对象感知与角色呈现](../../基础版/子模块/M3-S2-对象感知与角色呈现.md)

## 与基础版差异摘要

对象出现/消失/移动/动作等常规分支**与基础版一致**(SM_TURN/WALK/RUN/APPEAR/DISAPPEAR/SPACEMOVE 族/ITEMSHOW 等,见基础版 M3-S2)。白猪版新增/扩展 4 类下行:

### SM_SHANGMA_OK(3413)/SM_XIAMA_OK(3414)——上马/下马成功

- 处理:`core/mir2.scenes.main.ground_hk.lua` 行 1275/1283(`map:addMsg{roleid=recog, ident, feature}`)。
- **body = `TFeature`(10B packed)**:short race / byte sex / byte hair / short weapon / short dress / short riding——**riding 字段即坐骑外观**,上/下马后必须重发完整 TFeature;
- TDefaultMessage:`recog`=目标 roleid;param/tag/series 未使用。
- 服务端要点:玩家上/下马成功后,向视野内广播对应消息并携带新 TFeature;客户端据此切换外观,无需其他消息。

### SM_ASS_BLOODHIT_MOVE(3558)——血剑位移动作

- 处理:`ground_hk.lua` 行 992(`checkExist(ident2, SM_ASS_BLOODHIT_MOVE)` → `self:addBLOODHIT(msg, ident2)`);`role_hk.lua` 行 1674 有动作分支。
- TDefaultMessage:recog=roleid、param/tag=x,y、series 低字节=dir(与动作族一致);body 未使用。
- 注:基础版 globa1 已定义 3558 但基础版客户端不用;白猪版实现为**血剑(刺客系)突进动作**。服务端广播该动作即可,无应答。

### SM_YSGUISHU(1314)——特效指令通道(白猪独有)

- 处理:`ground_hk.lua` 行 1133。**param 决定子类型**,body=GBK 文本(部分分支 `^` 分段):

| param | 行为 | body 格式 |
|---|---|---|
| 0 | 怪物归属标记(`role.guishu = net.str(buf)`;受 `def.openYsGuiShu` 门控) | 归属文本 |
| 1 | 飘字:`piaoId=parts[2]`,`piaoNumber=parts[1]` | `数量^飘字ID` |
| 2 | buff 名展示:`buffName=parts[6]` | `^` 分段,第 6 段为 buff 名 |
| 3 | 暴击飘字(baoji) | — |
| 4 | 自身方向特效(`dir` 展示) | `^` 分段 |

- TDefaultMessage:`recog`=目标 roleid(0 分支为怪物);其余字段随分支使用。
- 服务端要点:此消息是白猪的通用表现指令通道,不发不影响功能;若实现,param 语义如上。

### SM_ASS_BLOODHIT_MOVE 相关与悬空动作

- `SM_LYHIT` / `SM_SFZHIT` / `SM_XHHIT` 在 `role_hk.lua`(行 1585/1597/1573)有动作分支(magicId 320/392/321),但 **globa1 无定义 → 分支不可达**,服务端无法触发,如实标注"悬空引用,勿实现"。

## 服务端实现要点

1. 上/下马必带完整 TFeature(10B);
2. 特效指令族(YSGUISHU/ASS_BLOODHIT_MOVE)可选实现;
3. 其余同基础版 M3-S2。
