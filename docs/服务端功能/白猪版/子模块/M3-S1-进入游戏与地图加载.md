# M3-S1 进入游戏与地图加载

> 所属主模块:[M3-游戏世界与场景](../主模块/M3-游戏世界与场景.md) · 基础版对照:[M3-S1 进入游戏与地图加载](../../基础版/子模块/M3-S1-进入游戏与地图加载.md)

## 与基础版差异摘要

**协议无差异。** 白猪版 main 场景进图链与基础版一致:

- `CM_LOGINNOTICEOK(1018)` + 80B 全零 TOsVersion3(main 场景 ctor 发出);
- `net.setWaitMsg(SM_NEWMAP, SM_MAPINFO_EX)` 阻塞,直到收到地图消息;
- `SM_LOGON(50)` → `SM_NEWMAP(51)` / `SM_MAPINFO_EX(1281)` → `SM_MAPDESCRIPTION(54)` 等,布局同基础版。

白猪版唯一差异:main 场景 ctor 会额外执行白猪初始化(`checkMd5` 门禁与 `core_func_byby`,本地防篡改,无网络报文;失败 `endToLua` 退出)。

## 服务端实现要点

按基础版 M3-S1 实现;进图序列不变。
