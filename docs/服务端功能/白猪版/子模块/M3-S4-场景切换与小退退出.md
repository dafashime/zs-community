# M3-S4 场景切换与小退退出

> 所属主模块:[M3-游戏世界与场景](../主模块/M3-游戏世界与场景.md) · 基础版对照:[M3-S4 场景切换与小退退出](../../基础版/子模块/M3-S4-场景切换与小退退出.md)

## 与基础版差异摘要

**协议无差异。** 白猪版与基础版一致:

- 切图 `SM_CHANGEMAP(634)`(param/tag=落点,body 第 1 段=地图 ID),不回 SM_LOGON;
- 小退 `CM_SOFTCLOSE(1009)` → 回 `SM_CHR_LIST(4010)`(recog=1);
- 大退无报文,以 TCP 断开为准;
- 踢线/顶号/排队/维护分支同基础版(M3-S4 详述);
- 回城 `CM_CLICK_BACKHOME(4633)`(5s 节流,无参无 body)同样存在于白猪版(`common.backHome`)。

## 服务端实现要点

按基础版 M3-S4 实现即可。
