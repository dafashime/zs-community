# M4-S4 系统消息与提示

> 所属主模块:[M4-战斗属性与技能](../主模块/M4-战斗属性与技能.md) · 基础版对照:[M4-S4 系统消息与提示](../../基础版/子模块/M4-S4-系统消息与提示.md)

## 与基础版差异摘要

聊天八件套(SM_HEAR 40/SM_GROUPMESSAGE 101/SM_CRY 102/SM_WHISPER 103/SM_GUILDMESSAGE 104/SM_BROADCASTMESSAGE 106/SM_CORPSMESSAGE 108/SM_SYSMESSAGE 100)的 body 布局(`/` 分割 GBK 文本、param 低/高字节颜色)与 SM_CLIENT_CONF(2953) 屏蔽掩码——**与基础版完全一致**。

### 白猪版特有:聊天文本遥控指令通道(核心差异)

白猪版 `mir2/mir2.data.chat.lua :: addMsg → processMsg` 会把**每一条聊天下行**先交给 `mir2/mir2.bz.functions.lua :: process_bz_cmd(text, response)`:

- **返回 true = 该条消息被消费**(不显示在聊天窗);返回 false/其余 = 正常显示;
- 文本以特定前缀开头时执行本地动作并消费:

| 前缀(文本开头) | 行为 |
|---|---|
| `FLTR\|` | 角色名过滤:`FLTR\|<色>\|<roleid>\|<毫秒>` → 给指定 roleid 开过滤(变色/隐藏),毫秒后自动关闭;部分分支客户端会**回发 CM_SAY** `"FLTR\|gray\|<roleid>\|<毫秒>"`(见 M7-S1) |
| `FROFF\|` | 关闭过滤:`FROFF\|<名>\|<roleid>` |
| `qie\|` / `ppp\|` / `bj\|` / `rrs\|` / `ccc` / `BL` | 血条样式/飘字样式切换(本地) |
| `MARKLEVEL` / `SHOWMELEVEL` | 等级显示开关(本地) |
| `OSSGS:` | 归属标记:`OSSGS:<roleid>:<归属文本>` |
| `QIE%d+` / `BJ%d+` / `FU%d+` | 飘字特效 |
| 特定句子 | "已经正式加入了本战队"→ 自动刷新战队/行会列表(CM_CORPS_MEMBER_LIST/CM_CORPS_LIST/CM_GILD_LIST/CM_GILDMEMBER_LIST);"的入队请求"/"被逐出战队"/"击杀了"等 → 消费不显示 |

- **分隔符约定**:`bzmir.hline = "|"`(`mir2/mir2.init.lua`),`bzmir.mh = ":"`,命令前缀 `bzmir.mcmd = "@"`。
- 服务端要点:这些前缀文本经**任意聊天频道**下发即可驱动白猪客户端本地行为;服务端要实现"遥控客户端"能力时,在目标玩家可见的频道(SM_HEAR/SM_SYSMESSAGE 等)发上述格式文本;同时需识别客户端回发的 `FLTR|`/`FROFF|` 前缀 CM_SAY(见 M7-S1)。

## 服务端实现要点

1. 基础聊天布局同基础版 M4-S4;
2. 可选实现遥控指令通道(前缀文本协议如上);
3. 白猪版数据层对系统消息的 zone 过滤(`def.hideOtherZoneMsg`/smallzone)为本地行为,不影响服务端。
