# M7-S1 聊天频道

> 所属主模块:[M7-社交系统](../主模块/M7-社交系统.md) · 基础版对照:[M7-S1 聊天频道](../../基础版/子模块/M7-S1-聊天频道.md)

## 与基础版差异摘要

CM_SAY(3030) 频道前缀语法(`!`、`/名字`、`!!`、`!#`、`!~`、`@传`)、下行八件套布局(见 [M4-S4](M4-S4-系统消息与提示.md))、SM_CLIENT_CONF(2953) 屏蔽掩码、CM_SWITCH_LISTEN(3032)——**与基础版完全一致**。

### 白猪版特有:遥控指令回执(客户端→服务端)

白猪版 `mir2/mir2.bz.functions.lua` 在解析服务端下发的指令文本后,部分场景会**主动回发 CM_SAY(3030)**,文本格式(分隔符 `bzmir.hline = "|"`):

| 回执文本格式 | 触发场景 | 语义 |
|---|---|---|
| `FLTR\|gray\|<roleid>\|<毫秒>` | CM_BANMOVE 指令(封禁移动)带超时且无颜色参数 | 请求对 roleid 开启灰色过滤(禁止移动表现)毫秒 |
| `FLTR\|<色>\|<roleid>\|<毫秒>` | CM_BANMOVE 带颜色参数 | 同上,指定颜色 |
| `FLTR\|<色>\|<名>\|<值>` | CM_FILTER 指令 | 按名字+值过滤 |
| `FROFF\|<名>\|<roleid>` | OFFFILTER 指令 | 请求关闭过滤 |

服务端要点:识别这些前缀的 CM_SAY(与普通发言区分),按语义执行/回执;这些回执是白猪"服务端遥控客户端"闭环的一部分(下发指令 → 客户端回执 → 服务端确认)。若服务端不实现遥控协议,客户端正常聊天不受影响(这些前缀文本不会被普通玩家打出)。

## 服务端实现要点

1. 基础聊天同基础版 M7-S1;
2. 可选实现 FLTR/FROFF 前缀协议(含识别与回执);
3. 白猪版有本地聊天过滤逻辑(zone 过滤/`def.hideString`),不影响服务端。
