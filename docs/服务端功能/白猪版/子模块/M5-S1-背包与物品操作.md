# M5-S1 背包与物品操作

> 所属主模块:[M5-物品与装备](../主模块/M5-物品与装备.md) · 基础版对照:[M5-S1 背包与物品操作](../../基础版/子模块/M5-S1-背包与物品操作.md)

## 与基础版差异摘要

SM_BAGITEMS(201)/SM_ADDITEM/SM_DELITEM/SM_UPDATEITEM、地面物品(SM_ITEMSHOW 610/SM_ITEMHIDE 611,body=TFloorItem)、拾取 CM_PICKUP(1001)、丢弃 CM_DROPOITEM、使用 CM_EAT(1006)、堆叠 CM_PILEUPITEM(1115,series=0/1)等——**与基础版完全一致**。

### 白猪版差异点

1. **刷新按钮**:bag8/9/10/New 面板提供刷新入口(`bagNew.lua` 行 93-103):`CM_QUERYBAGITEMS(81)` 无参无 body,1 秒节流(`queryBag`);服务端应以 SM_BAGITEMS 全量应答;
2. **双击使用**:白猪版 `core/mir2.scenes.main.common.item_hk.lua`(行 394-395/486-487)双击物品直接发:
   - 装备 → `CM_TAKEONITEM(1003){recog=makeIndex, param=位置}` + strs=名字;
   - 消耗品 → `CM_EAT(1006){recog=makeIndex}`;
   - **不再发 CM_DBLCLICKUSEITEM(1017)**(基础版 `itemInfo.lua` 行 624 使用该消息);
3. CM_PASS_OK/bagNeedPass:白猪版有"背包加锁/二次确认"(本地事件 `_Events.CM_PASS_OK`、`g_data.player.bagNeedPass`),纯本地,无新增报文;
4. 英雄/主角容器区分(series=1)、一键换装流程见 M5-S2。

## 服务端实现要点

1. 响应 CM_QUERYBAGITEMS 时回 SM_BAGITEMS 全量(客户端按 bufLen/16 解析);
2. 双击使用按 TAKEONITEM/EAT 处理;无需实现 DBLCLICKUSEITEM(白猪版客户端不会发)。
