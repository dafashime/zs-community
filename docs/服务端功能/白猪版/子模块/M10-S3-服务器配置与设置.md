# M10-S3 服务器配置与设置

> 所属主模块:[M10-辅助系统](../主模块/M10-辅助系统.md) · 基础版对照:[M10-S3 服务器配置与设置](../../基础版/子模块/M10-S3-服务器配置与设置.md)

## 与基础版差异摘要

**协议无差异。** 白猪版 `mir2.data.serverConfig.lua`/`setting.lua` 与基础版一致:

- `g_data.serverConfig` **无网络来源**(allowMaxLevel 恒 999,本地默认);
- 设置项无 CM_SETSERVERCONFIG 类报文;
- 自动吃药/自动技能等设置触发的消息(CM_EAT 1006/CM_SPELL 3017 等)复用基础消息。

白猪版特有:`def.smallzoneCfg`(分区配置,本地表,用于系统消息 zone 前缀显示,见 M4-S4)与 `def.hideString`/`def.hideOtherZoneMsg`(跨区消息过滤,本地)。

## 服务端实现要点

按基础版 M10-S3 实现。
