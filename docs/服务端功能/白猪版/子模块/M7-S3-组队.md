**协议无差异。** SM_GROUPMEMBERS(667,recog=人数,body=TClientGroupMemInfo 54B/条)、SM_NEARBYGROUPMEMBERS(TClientNearbyGroupInfo 36B)、组队操作(CM_GROUPMODE/CM_CREATEGROUP/CM_ADDGROUPMEMBER/CM_DELGROUPMEMBER/CM_JOINGROUP)与基础版一致。

白猪版 `core/mir2.scenes.main.panel.group.lua` 仅 UI 差异;near 面板的组队入口复用上述消息。
