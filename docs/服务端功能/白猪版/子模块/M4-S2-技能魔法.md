## 与基础版差异摘要

**协议无差异。** 白猪版与基础版一致:

- CM_SPELL(3017) 施法(无 body,坐标/目标在 TDefaultMessage 字段,见基础版 M4-S2);
- CM_MAGICKEYCHANGE(1008) 技能热键上报(recog=magicId,param=按键 ASCII 或 0);
- SM_SENDMYMAGIC(211)/SM_ADDMAGIC(210)/SM_DELMAGIC(212)/SM_MAGIC_LVEXP(640):body=TNewClientMagic(packed 46B)数组/单条;SM_MAGICFIRE(638)/SM_MAGICFIRE_FAIL(639) 驱动施法节流。

白猪版 `core/mir2.scenes.main.console.skills.lua`/`magic.lua` 仅 UI 差异。

## 服务端实现要点

按基础版 M4-S2 实现。
