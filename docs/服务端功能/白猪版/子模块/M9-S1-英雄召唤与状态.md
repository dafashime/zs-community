## 与基础版差异摘要

召唤/收回(CM_HERO_LOGON 1050/CM_HERO_LOGOUT 1051)、锁定/守卫(CM_HERO_APPTARG 1105)、状态开关(CM_HERO_CHGSTATE 1107)、英雄状态下发(SM_HERO_LOGON 899/SM_HERO_ABILITY 900/SM_HERO_LEVELUP 914/SM_HERO_WINEXP 915/GLORYFEALTY 960/UNIONSTATUS 923)——**与基础版完全一致**(基础版 M9-S1 详述)。

### 白猪版特有:英雄自动上马

`core/mir2.scenes.main.role.hero.lua :: autoHorse`(行 471-480):

- 条件:与目标切比雪夫距离 **≥10 格**、`self.horse == 0`(未上马)、非挂机(`autoRat.enableRat` 关闭)、`g_data.titleBag:getIsRideHorse()`(坐骑权限,称号背包系统,本地);
- 报文:`net.send({ CM_SHANGMA_OK, param = 1 })`——param=1 上马请求,无 body;
- 下行:SM_SHANGMA_OK(3413)/SM_XIAMA_OK(3414),`recog`=英雄 roleid,body=TFeature(10B,riding 变化)——处理见 [M3-S2](M3-S2-对象感知与角色呈现.md);
- 服务端要点:收到 CM_SHANGMA_OK(param=1)后校验坐骑权限,成功后向视野广播 SM_SHANGMA_OK + 新 TFeature;下马由服务端或客户端其他路径触发(未核实是否有 param=0 下行请求)。

## 服务端实现要点

按基础版 M9-S1 实现 + 上马协议(CM_SHANGMA_OK → SM_SHANGMA_OK/TFeature)。
