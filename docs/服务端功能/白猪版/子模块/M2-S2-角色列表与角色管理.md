# M2-S2 角色列表与角色管理

> 所属主模块:[M2-选区与角色管理](../主模块/M2-选区与角色管理.md) · 基础版对照:[M2-S2 角色列表与角色管理](../../基础版/子模块/M2-S2-角色列表与角色管理.md)

## 与基础版差异摘要

**协议无差异。** 已逐条对照白猪版与基础版 `mir2.scenes.select.scene.lua` 的全部 `net.send`/`SM_`/`CM_` 引用点——消息集合完全一致(仅行号/变量名不同):

| 消息 | 值 | 说明 |
|---|---|---|
| CM_SELCHR | 4017 | 进入游戏(strs=角色名) |
| CM_DELCHR / CM_QUERYDELCHR / CM_RECOVERCHR | 4006/4007/4008 | 删除/查询删除/恢复(白猪版同基础版:删除带密码 strs) |
| CM_SELCHR_EXIT | 4009 | 返回登录 |
| CM_NEWCHR | 4013 | 创建角色(参数同基础版) |
| CM_SUBMIT_MIBAO | 4046 | 密保提交 |
| SM_NEWCHR / SM_CHR_LIST / SM_DELCHR / SM_SELCHR / SM_QUERYDELCHR / SM_RECOVERCHR / SM_VAILDATE_PPWD / SM_ACK_TRANSFER_AREA | — | 分支处理同基础版(数值见基础版 M2-S2) |
| SM_LOGIN → CM_RECONNECT | 4003/4031→802 | 重连票据流,同基础版 |

角色列表布局:SM_CHR_LIST(4010) recog=1、param=数量、tag=选中索引、body=TMirCharinfoEx(22B)/TMirCharInfo(20B);跨服转移 SM_ACK_TRANSFER_AREA body=TRetTransferAreaInfo(81B packed,总长 82B)。全部与基础版相同。

## 服务端实现要点

按基础版 M2-S2 实现即可;白猪版无新增选角协议。
