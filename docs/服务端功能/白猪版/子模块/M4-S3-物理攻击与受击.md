## 与基础版差异摘要

攻击上行(CM_HIT 族,recog=x/param=y/series=dir,无 body)、受击(SM_STRUCK 31 双格式)、死亡回生、SM_PHYSICAL_ATT(1230) hitMode 映射表——**全部与基础版一致**(白猪版 `ground_hk.lua` 行 996-1027 的 hitMode 映射:1000→SM_HIT、1001→SM_HEAVYHIT、1002→SM_BIGHIT、1003→SM_POWERHIT、1004→SM_LONGHIT、1005→SM_WIDEHIT、1007→SM_FIREHIT、1011→SM_HERO_LONGHIT、1012→SM_HERO_LASTHIT、1013→SM_SQUARE_HIT、1015→SM_SWORD_HIT、1017→SM_HundredHit、1018→SM_HORIZONHIT,与基础版相同)。

### 白猪版新动作分支(全部悬空,不可达)

`core/mir2.scenes.main.role.role_hk.lua` 存在以下动作分支,但对应常量**在 globa1 中无定义**,运行时 ident 为 nil → 分支不可达:

| 分支 | 代码意图 | 状态 |
|---|---|---|
| SM_XHHIT | magicId=321,type="fire"(血痕类) | 悬空引用 |
| SM_LYHIT | magicId=320,type="fire"(龙渊类) | 悬空引用 |
| SM_SFZHIT | magicId=392,type="sfz"(弑法类) | 悬空引用 |
| SM_4FIREHIT | magicId=26,type="fire"(四重烈火) | 悬空引用(基础版同样存在) |

服务端发送任何 ident 都无法命中;这些分支是反编译残留,勿据其实现。

### 受击/动作广播

- SM_STRUCK(31):body 16B(读 msg 字段)或 32B(TStruckInfo),同基础版;
- SM_HEALTHSPELLCHANGED(53)/SM_OPENHEALTH(1100)/SM_CLOSEHEALTH(1101) 同基础版;
- 击杀流程 SM_DEATH(32)/SM_NOWDEATH(34)/SM_ALIVE(27) 同基础版。

## 服务端实现要点

按基础版 M4-S3 实现;忽略悬空动作分支。
