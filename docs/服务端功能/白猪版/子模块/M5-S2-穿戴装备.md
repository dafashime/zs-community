# M5-S2 穿戴装备

> 所属主模块:[M5-物品与装备](../主模块/M5-物品与装备.md) · 基础版对照:[M5-S2 穿戴装备](../../基础版/子模块/M5-S2-穿戴装备.md)

## 与基础版差异摘要

CM_TAKEONITEM(1003)/CM_TAKEOFFITEM(1004)(recog=makeIndex、param=装备位、strs=名字)、SM_TAKEON_OK/FAIL、SM_TAKEOFF_OK/FAIL、SM_FEATURECHANGED(41,body=TFeature)——**与基础版完全一致**。

### 白猪版特有:一键换装(脚本事件驱动)

`mir2/mir2.bz.functions.lua` 解析服务端下发的指令文本(经聊天通道,见 M4-S4/M7-S1),`CM_TAKEOFF`/`CM_RSITEM` 事件触发换装序列:

1. `CM_TAKEOFF` 事件(`bz.functions.lua` 行 2207):脱下指定装备位——`CM_TAKEOFFITEM{recog=makeIndex, param=装备位}` + strs=名字;
2. `CM_RSITEM` 事件(行 2225,一键换装):同样先脱,然后 `def.role.autoRun(..., 0.2)` 延迟 0.2s,若背包存在同名同型物品则 `CM_TAKEONITEM{recog=新makeIndex, param=装备位}` + strs=名字。

服务端要点:两条 CM 序列与基础版单条穿脱完全相同,服务端无需特殊处理;注意 0.2s 延迟内客户端可能先发脱下后发穿上。

## 服务端实现要点

按基础版 M5-S2 实现;一键换装只是两条标准消息的先后组合。
