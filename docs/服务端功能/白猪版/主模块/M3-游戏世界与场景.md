## 模块边界

进图初始数据、地图加载、对象感知与呈现、自身移动、切图与小退退出。与基础版协议同源,差异集中在**移动扩展与坐骑/范围拾取**:

1. **CM_RUN3(4108) 三格跑步**:自动寻路/点击移动距离为 3 格时发 CM_RUN3(基础版只有 1 格 CM_WALK / 2 格 CM_RUN)——见 [M3-S3](../子模块/M3-S3-自身移动与位置交互.md);
2. **范围拾取**:CM_PICKUP_RANGE(4278) 请求 + SM_MAP_RANGE_PICK(5044) 开关回执(白猪独有常量)——见 [M3-S3](../子模块/M3-S3-自身移动与位置交互.md);
3. **坐骑上/下马**:CM_SHANGMA_OK(4106) 上行(英雄自动上马)+ SM_SHANGMA_OK(3413)/SM_XIAMA_OK(3414) 下行(body=TFeature)——见 [M3-S2](../子模块/M3-S2-对象感知与角色呈现.md) 与 [M9-S1](../子模块/M9-S1-英雄召唤与状态.md);
4. **特效指令扩展**:SM_YSGUISHU(1314,白猪独有)param 0~4+ 分支(归属标记/飘字/buff/暴击)、SM_ASS_BLOODHIT_MOVE(3558,血剑位移)——见 [M3-S2](../子模块/M3-S2-对象感知与角色呈现.md);
5. 进图/切图/小退/重连流程与基础版**一致**(SM_NEWMAP/SM_MAPINFO_EX 等待语义、CM_SOFTCLOSE→SM_CHR_LIST、SM_CHANGEMAP 等)。

## 服务端实现要点

1. 支持 3 格跑步(CM_RUN3)并广播对应移动;基础版服务端若不支持,白猪版点击远距离会多发一条 RUN3(可忽略或按 RUN 处理);
2. 范围拾取:收到 CM_PICKUP_RANGE 后回 SM_MAP_RANGE_PICK(param=1),并把范围内物品以 SM_ITEMSHOW/拾取结果下推;
3. 坐骑:SM_SHANGMA_OK/SM_XIAMA_OK 必须带完整 TFeature(10B),客户端用它刷新外观;
4. SM_YSGUISHU/SM_ASS_BLOODHIT_MOVE 为表现指令,不发不影响功能;
5. 其余按基础版 M3 实现。
