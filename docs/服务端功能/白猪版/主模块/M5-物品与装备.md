# M5 物品与装备

> 所属系列:[白猪版服务端功能文档](../目录.md) · 基础版对照:[M5-物品与装备](../../基础版/主模块/M5-物品与装备.md)

## 模块边界

背包、穿戴、仓库、强化合成宝箱、配药。与基础版协议**同号同布局**(TStdItem 56B/TClientItem packed 16B+扩展键 2B×KeyValueSize、SM_BAGITEMS/SM_ADDITEM/SM_DELITEM/SM_UPDATEITEM、CM_TAKEONITEM/CM_TAKEOFFITEM/CM_EAT/CM_DROPITEM/CM_PILEUPITEM 等),差异集中在**多格背包 UI 与操作入口**:

1. 白猪版提供 bag8/bag9/bag10/bagNew 四套背包面板,报文相同;新增"刷新"按钮 → `CM_QUERYBAGITEMS(81)`(1s 节流)——见 [M5-S1](../子模块/M5-S1-背包与物品操作.md);
2. **双击使用不再发 CM_DBLCLICKUSEITEM(1017)**:白猪版 `item_hk.lua` 双击直接发 CM_TAKEONITEM/CM_EAT(基础版 itemInfo 用 DBLCLICKUSEITEM)——见 [M5-S1](../子模块/M5-S1-背包与物品操作.md);
3. 一键换装(脚本事件 RSITEM):CM_TAKEOFFITEM → 0.2s 后 CM_TAKEONITEM 序列——见 [M5-S2](../子模块/M5-S2-穿戴装备.md);
4. 仓库/强化/宝箱/配药与基础版一致。

## 消息号速查表(白猪版差异项)

| 消息 | 值 | 方向 | 说明 |
|---|---|---|---|
| CM_QUERYBAGITEMS | 81 | C→S | 请求背包全量(基础版同有;白猪版面板刷新按钮使用) |
| CM_DBLCLICKUSEITEM | 1017 | C→S | **白猪版不用**(仅基础版用;值同) |

## 服务端实现要点

按基础版 M5 实现;白猪版多格背包的格数通过 SM_BAGITEMS 数量表达(未发现扩容专用消息,如 bag10 面板按本地配置显示,以代码为准(未核实))。
