# M9 英雄系统

> 所属系列:[白猪版服务端功能文档](../目录.md) · 基础版对照:[M9-英雄系统](../../基础版/主模块/M9-英雄系统.md)

## 模块边界

英雄召唤/状态/背包装备。与基础版协议同号同布局(英雄独立消息号段 1050-1109/896-925、CM_PILEUPITEM series=1、recog 归户模式),差异:

1. **英雄自动上马**:`CM_SHANGMA_OK(4106){param=1}`——英雄跟随跑动距离≥10 格且未上马时自动发出,对应下行 SM_SHANGMA_OK(3413)/SM_XIAMA_OK(3414,body=TFeature)——见 [M9-S1](../子模块/M9-S1-英雄召唤与状态.md);
2. 其余(召唤/收回/锁定/背包装备/技能列表)与基础版一致——见 [M9-S2](../子模块/M9-S2-英雄背包与装备.md)。
