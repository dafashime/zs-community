# M10 辅助系统

> 所属系列:[白猪版服务端功能文档](../目录.md) · 基础版对照:[M10-辅助系统](../../基础版/主模块/M10-辅助系统.md)

## 模块边界

邮件、安全密保、服务器配置、大地图标记、语音、快捷键与杂项。与基础版协议同号同布局,差异:

1. **webView 面板**:纯 WebView(默认百度;chargeNew 教程页复用)——见 [M10-S6](../子模块/M10-S6-快捷键GM命令与杂项.md);
2. **动态面板工厂**(panelFactory/luaPanelFactory):本地面板基础设施,交互走 @命令通道——见 [M10-S6](../子模块/M10-S6-快捷键GM命令与杂项.md);
3. **商城 mall**:生产热更树存在 `mir2.data.mall.bc`(字节码),**明文树无实现**,协议未知——见 [M10-S6](../子模块/M10-S6-快捷键GM命令与杂项.md);
4. 邮件/密保/配置/标记/语音/GM 命令与基础版一致。
