# M1 登录与接入

> 所属系列:[白猪版服务端功能文档](../目录.md) · 基础版对照:[M1-登录与接入](../../基础版/主模块/M1-登录与接入.md)

## 模块边界

覆盖白猪版客户端的 HTTP 登录中心交互、TCP 网关连接与握手、账号登录序列、公告与断线重连。与基础版协议**高度同源**,差异集中在:

1. **TigerGate 可选加密层 + cmd=29 心跳**(net.lua 新增,默认关闭)——见 [M1-S2](../子模块/M1-S2-TCP握手加密与心跳.md),这是白猪版**唯一的传输层差异**;
2. HTTP 登录中心地址改用 `bzmir.gateIP/gatePort`(由 `def.setLoginCenter` 写入),并新增 **serverTime 时钟校准轮询**——见 [M1-S1](../子模块/M1-S1-HTTP登录中心接口.md);
3. 账号登录序列与基础版一致(HTTP 取票 → CM_LOGIN_AUTH),白猪版**同样不发 CM_IDPASSWORD**——见 [M1-S3](../子模块/M1-S3-TCP账号登录流程.md);
4. 公告/重连流程一致,新增 `mir2.scenes.bz.scene.lua` 白猪专属场景(登录后过渡)——见 [M1-S4](../子模块/M1-S4-公告与断线重连.md)。

## 消息号速查表(白猪版差异项)

| 消息 | 值 | 方向 | 说明 |
|---|---|---|---|
| cmd=29(心跳) | — | C→S | 白猪版 net.lua 新增,30s 周期,仅 TigerGate 编码生效时携带轮转种子 |
| (其余) | — | — | 全部与基础版同值同义,见基础版 M1 速查表 |

## 服务端实现要点

1. 帧协议/登录序列按基础版实现即可兼容白猪版;
2. 预留 TigerGate 解码(上行文本帧判别 + 变体 base64 逆变 + 种子维护),当前无需启用;
3. `/account` 响应建议带 `stime` 字段(白猪版客户端会轮询校准本地时钟,缺失时不影响登录但客户端日志无校准)。
