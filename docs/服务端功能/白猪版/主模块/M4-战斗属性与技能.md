# M4 战斗属性与技能

> 所属系列:[白猪版服务端功能文档](../目录.md) · 基础版对照:[M4-战斗属性与技能](../../基础版/主模块/M4-战斗属性与技能.md)

## 模块边界

属性能力下发、技能魔法、物理攻击与受击、系统消息。与基础版协议**同号同布局**(TAllAbility 184B、TNewClientMagic 46B packed、TStruckInfo 32B 等全部一致),差异仅在**攻击动作族扩展**:

1. 新技能动作分支(SM_XHHIT/LYHIT/SFZHIT/4FIREHIT)在白猪版 `role_hk.lua` 存在,**但全部为悬空引用**(globa1 无定义,分支不可达)——见 [M4-S3](../子模块/M4-S3-物理攻击与受击.md);
2. `SM_PHYSICAL_ATT(1230)` hitMode 映射表与基础版一致(含 1017/1018);
3. 属性/技能/系统消息通道与基础版完全一致。
