# M2 选区与角色管理

> 所属系列:[白猪版服务端功能文档](../目录.md) · 基础版对照:[M2-选区与角色管理](../../基础版/主模块/M2-选区与角色管理.md)

## 模块边界

私服列表(sfselect)、角色列表/创建/删除/恢复/选择、密保提交。白猪版与基础版协议**完全一致**(对照 `mir2.scenes.select.scene.lua`/`sfselect.*` 与基础版,差异仅为 UI 与变量名):

- 角色列表仍由服务端主动推 `SM_CHR_LIST(4010)`(recog=1,param=数量,tag=选中索引,body=TMirCharinfoEx 22B/条);
- 选人场景 net.match 白名单 9 条不变(CM_SELCHR/CM_DELCHR/CM_QUERYDELCHR/CM_SELCHR_EXIT/CM_NEWCHR/CM_RECOVERCHR/CM_SUBMIT_MIBAO/CM_RECONNECT/CM_LOGIN_ALREADY_ONLINE);
- 创建/删除/恢复/密保提交消息号与布局同基础版(M2-S2 详述)。

## 消息号速查表

与基础版 M2 速查表完全一致(约 31 条有效消息),此处不重复;数值以白猪版 `mir2.def.globa1.lua` 为准(与基础版同值)。唯一注意:`SM_RECONNECT` 运行时值同样为 **802**(globa1 行 991 覆盖行 584 的 4031)。

## 服务端实现要点

按基础版 M2 实现即可;白猪版无新增选人协议。
