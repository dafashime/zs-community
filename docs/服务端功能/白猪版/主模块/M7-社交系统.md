# M7 社交系统

> 所属系列:[白猪版服务端功能文档](../目录.md) · 基础版对照:[M7-社交系统](../../基础版/主模块/M7-社交系统.md)

## 模块边界

聊天频道、好友关系、组队、行会。与基础版协议**同号同布局**,差异:

1. **聊天遥控回执(核心)**:白猪版客户端在收到特定前缀聊天文本后会**主动回发 CM_SAY**(FLTR|/FROFF| 过滤回执)——见 [M7-S1](../子模块/M7-S1-聊天频道.md) 与 [M4-S4](../子模块/M4-S4-系统消息与提示.md);
2. 好友/组队/行会全部消息与基础版一致(near 附近玩家面板复用 CM_QUERYUSERSTATE/好友增删/组队邀请等基础消息)——见 [M7-S2](../子模块/M7-S2-好友关系.md)/[M7-S3](../子模块/M7-S3-组队.md)/[M7-S4](../子模块/M7-S4-行会.md)。
