# 功能模块对比：基础版（rebuilt-src-bs） vs 白猪 G2.5（rebuilt-src-bz）

> 生成日期：2026-08-25。数据来源：`rebuilt-src-bs`（327 文件）与 `rebuilt-src-bz/白猪G2.5_0518_lua_plain_readable_20260710_014719`（mir2 203 + core 82 + upt 6 = 291 模块，32 位份）。
> 本对比用于"基于基础版逐步搬迁白猪功能"的选型参考：同名模块 = 可直接替换/对照；白猪新增 = 需移植；基础版独有 = 保持不动。

## 总览

| 类别 | 数量 | 含义 |
|---|---|---|
| 同名模块 | 222 | 两套都有（模块名一致） |
| 基础版独有 | 105 | 基础版有、白猪无（含 framework/an 框架层 103 个 + mir2.* 若干） |
| 白猪新增 | 63 | 白猪有、基础版无（含白猪专属 bz.functions/def.bzinit/gb2312 等 + 新面板族） |

- 模块体系**同源同构**：大多数模块名一一对应，白猪 = 基础版（战神/红月家族）的商业魔改版。
- 框架层不同：基础版用 an.*(20) + framework.*(83)；白猪用自研 core（对应文件在 core/，模块名多为 mir2.*），故 framework/an 全部显示为基础版独有。
- 大小对比：G2.5/基础版 比值 > 1.4 视为白猪侧扩展/重写；< 0.7 视为白猪侧精简。

## 备注

1. **白猪登录链 = 白猪重写**：`scenes.login.*`（login 22K/9K、scene 13K/12K、areas 24K/15K）与 `single.net`(16.8K/13.4K) 均为白猪侧扩展，且登录端点/轮询机制与基础版不同（base: `def.loginCenterIP/Port` 直连；白猪: `bzmir.gateIP/gatePort` + `def.role.createRepeater` + isAoth/isloaded，由 `def.bzinit` 驱动）。
2. **`mir2.def.role` 仅基础版有**：白猪的 def.role 只在 NPJ 出厂加密包（`mir2_encrypted.zip`），G2.5 明文与热更 204 均无；当前 mod 用 bs 版顶替（`rebuilt-src-bz-prod/reference/`）。
3. **迁移建议顺序**：先数据/配置层（data/def，同名且≈同量级，风险最低）→ helperScript/单例 → 登录链 → 面板/控制台（白猪新面板族 bag8-10/storage8-10 需整体移植）。
4. 本表按 32 位份统计；64 位份（mir264/core64/upt64）与 32 位模块一致。
